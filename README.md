# 초강대국 학교 (가상/창작)

> ⚠️ 이 프로젝트는 **창작 세계관을 위한 가상 학교 웹사이트**입니다.  
> 실제 학교·기관·정부·법률과 **아무 관련이 없습니다.**

---

## 개요
- 배경: 2035년 전후 대한민국(현대와 거의 동일)
- 설정: 인구 1~2%가 **특이능력사용자(특능자)**
- 공개 계기: 2028 **한강 브레이크 사건**
- 목적: 세계관 소개용 **가짜 학교 홈페이지 + 가짜 입학상담 챗(스크립트형)**

---

## 포함 기능
- 정적 웹사이트(HTML/CSS/JS)
- 입학/학교소개/교칙/공지 페이지
- “입학상담 AI” 페이지(서버 없이 동작)

---



## 배포(GitHub Pages)

3) Branch: main / Folder: /(root)  
4) 저장 후 생성된 URL로 접속
